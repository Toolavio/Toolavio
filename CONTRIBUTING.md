# Contributing feedback and documentation

Thank you for helping make Toolavio easier to understand and use.

**This repository is a public presentation and feedback hub. It is not the Toolavio application source repository.**

## Useful contributions

Use the [issue forms](https://github.com/Toolavio/Toolavio/issues/new/choose) for reproducible bugs, practical feature suggestions, translation feedback, or unclear documentation. Explain the task and expected outcome instead of only proposing another button or tool name.

Small pull requests correcting this repository's public wording or links are welcome. Keep them focused, explain the change, and verify relative links. Product release history should remain linked to the official [Updates page](https://toolavio.com/en/updates.html), not copied into an independently maintained changelog.

## Keep private material private

Do not submit application source, extracted processing engines, deployment ZIPs, internal audits, credentials, user files, or private screenshots. Provide only material you are authorized to share publicly. Use fictional input data and review attachments before submission.

Screenshots must depict the actual product, identify the relevant page or workflow, and contain no private information. Do not submit mockups as proof that a feature exists or a conversion works.

Report vulnerabilities through the private channel in [SECURITY.md](SECURITY.md), never through a public pull request.

## Review and scope

A contribution does not guarantee acceptance or a product release. Documentation changes must distinguish currently available website features from planned Core and TAE work. Publishing this repository does not grant access to or an open-source license for Toolavio's software.
