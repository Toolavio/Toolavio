# Support and feedback

[Use Toolavio](https://toolavio.com/) · [Quick start](docs/QUICK_START.md) · [FAQ](docs/FAQ.md)

## Choose the right channel

| Question | Channel |
| --- | --- |
| A reproducible tool problem with no confidential data | [Bug report](https://github.com/Toolavio/Toolavio/issues/new?template=bug_report.yml) |
| A useful new capability or usability improvement | [Feature request](https://github.com/Toolavio/Toolavio/issues/new?template=feature_request.yml) |
| A typo, translation, broken documentation link, or unclear explanation | [Documentation feedback](https://github.com/Toolavio/Toolavio/issues/new?template=documentation.yml) |
| Account, billing, or another private matter | [contact@toolavio.com](mailto:contact@toolavio.com) |
| Suspected vulnerability or accidental data exposure | Follow [SECURITY.md](SECURITY.md) privately |

## A useful bug report

Include the public tool/page URL without private query parameters, browser and operating system, selected language, steps to reproduce, expected result, and actual result. Add a minimal fictional example when possible. Say whether the issue happens online, offline, or in an installed web app.

**GitHub issues and attachments are public.** Never post passwords, tokens, cookies, customer documents, personal records, payment details, proprietary source archives, or unredacted screenshots. Use synthetic inputs rather than real documents.

An error message can be useful after sensitive information is removed. Do not paste a full network log, HAR file, or console dump without reviewing it for secrets first.

## Before retrying

Keep the original and save important results. Check the tool's supported formats and limits. Try a smaller non-sensitive example, and consult [official updates](https://toolavio.com/en/updates.html). Clearing browser site data can delete local projects and prepared toolkits, so it is not a first troubleshooting step.

## Scope

This is a public documentation and feedback repository. It does not provide the application source or self-hosted deployment package. A report or request does not guarantee a response time, implementation, or release date. Current service terms remain on Toolavio.com.
