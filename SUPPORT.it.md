## Come rendere utile una segnalazione

Indica URL pubblico dello strumento o della pagina senza parametri privati, browser, sistema operativo, lingua selezionata, passaggi per riprodurre il problema, risultato atteso ed effettivo. Quando possibile aggiungi un esempio minimo inventato. Specifica se il problema avviene online, offline o nella web app installata.

**Le issue e gli allegati GitHub sono pubblici.** Non pubblicare password, token, cookie, documenti di clienti, dati personali, dettagli di pagamento, archivi sorgente proprietari o screenshot non oscurati. Usa input sintetici anziché documenti reali.

Un messaggio di errore può essere utile dopo aver rimosso le informazioni riservate. Non incollare log di rete completi, file HAR o dump della console senza averli prima controllati per escludere segreti.

## Prima di riprovare

Conserva l'originale e salva i risultati importanti. Controlla formati e limiti dello strumento. Prova un campione più piccolo e non riservato e consulta gli [aggiornamenti ufficiali](https://toolavio.com/it/updates.html). Cancellare i dati del sito può eliminare progetti locali e pacchetti preparati: non è il primo tentativo consigliato.

## Ambito

Questo repository contiene documentazione pubblica e raccoglie feedback. Non distribuisce il sorgente applicativo o un pacchetto self-hosted. Una segnalazione o richiesta non garantisce tempi di risposta, implementazione o date di rilascio. Le condizioni del servizio aggiornate restano su Toolavio.com.
