## Not eight programs to learn

The eight components belong to one platform. To convert an image or format text, you do not have to go through all of them: open the tool and complete the operation. The other capabilities help when the task calls for them.

This guide describes already documented website workflows, not new testing on every device. Features, options, and access can depend on the tool, format, and browser. The [official release notes](https://toolavio.com/en/updates.html) remain the reference for published changes.

## Choose in one sentence

| Your need | Capability to know |
| --- | --- |
| I know the result, but not the tool's name | Toolavio One |
| I already have the file to process | Universal Drop |
| I need several compatible transformations | Smart Chains, inside Flow |
| I want to understand which checks were performed | Proof Engine |
| I want to explicitly save work on my device | Private Vault |
| I want to find my tools and procedures again | My Toolavio |
| I want another person to repeat a procedure | Share a Workflow |
| I want to install the web app or prepare offline tools | Toolavio Everywhere |

## 1. Toolavio One — start with the goal

**When it helps:** you know the result you need, but not which tool to search for.

Describe the operation from the [homepage](https://toolavio.com/en/). Review the proposed result and, for a multi-step plan, read the transformations before starting.

The benefit is less searching through categories. A recognized request is mapped to supported operations; it is not a promise that any instruction can be executed. If the proposal does not match your goal, rephrase the request or choose the tool directly.

## 2. Universal Drop — start with the file

**When it helps:** you have a document or image and want to find compatible operations.

Select the file from the homepage or drop it where the control is available. Choose the appropriate operation and check that the input is present in the workspace. Compatible paths reuse the file without a second selection.

Not every format works with every tool. Multiple file selection requires an operation that supports it; memory and file size can limit work on the device.

## 3. Smart Chains — connect operations in Flow

**When it helps:** a result needs several transformations in sequence.

Open [Flow](https://toolavio.com/en/flow/), choose or assemble compatible steps, review the options, and run the procedure. Inspect available intermediate results before using the final output.

An example is applying CSV cleanup and converting the resulting table to JSON. Flow avoids manual transfer between supported steps; it does not make incompatible formats or operations compatible. Pay attention to warnings about transformations that can lose information.

## 4. Proof Engine — read what was checked

**When it helps:** you have a result and want to understand the available technical checks.

In the workspace or Flow, open the check details associated with the output. Read the type of check, not just a completion message.

Syntactically valid JSON can contain the wrong data for your goal; a decodable image can look different from its original. Proof is not universal certification of meaning, fidelity, OCR, signatures, or redaction. Important documents also require your review.

## 5. Private Vault — keep work locally

**When it helps:** you want to explicitly save supported content and reopen it in the same browser environment.

In [Flow](https://toolavio.com/en/flow/), use the available local-save actions and check what is being stored: a file, result, or project. Reopen and delete content within the interface's stated limits.

Vault is not cloud storage, cross-device synchronization, or a guaranteed backup. Clearing site data, storage limits, and browser behavior can affect retention. Download what you need to keep and take care on shared devices.

## 6. My Toolavio — return to what you use

**When it helps:** you repeatedly use the same tools or procedures.

Use My Toolavio on the homepage to find favorites and recent tools. In workflows, use supported presets to return to reusable settings.

A favorite is a shortcut; a preset describes a configuration; a saved project may include content when you authorize saving it. These are not the same thing. Local functions do not imply a cloud profile or automatic synchronization.

## 7. Share a Workflow — share the method

**When it helps:** you want a colleague or another person to repeat a supported sequence.

Use Share workflow in Flow. Review the configuration and choose a link, QR code, or available sharing method. The recipient opens the procedure and supplies their own inputs.

Always distinguish three actions: sharing a tool sends a link; sharing a workflow sends a procedure; sharing a result can send the generated file. Do not include confidential information in settings you share. Native channels and available destinations depend on the device.

## 8. Toolavio Everywhere — prepare use on your device

**When it helps:** you want easier access to the platform or selected functions without a connection.

Open [Offline](https://toolavio.com/en/offline/) while connected. Follow the guidance for your browser and prepare the resources needed by your tools. Test an operation before relying on it offline.

Installing the web app is not installing a separate native program distributed by this repository. It does not guarantee that every tool works without a network: downloaded resources, account services, the browser, and local storage still matter.

## Three choices that keep things simple

**One operation:** use its dedicated page. You do not need Flow.

**Several compatible operations:** use Flow and review the result of each important step.

**Work to keep or share:** explicitly choose between saving a local project, downloading the output, and sharing a procedure. Keep a copy of what matters before closing or clearing site data.

## What about Toolavio Core and TAE?

These are development initiatives separate from the eight capabilities described here. Core concerns extracting reusable components; Toolavio Action Engine concerns future integration in other websites. This guide offers no code, Core package, or commercially ready embed. Read the [public roadmap](ROADMAP.md).

The software remains private. Start with one of the [six use cases](USE_CASES.md) or open [Toolavio.com](https://toolavio.com/en/) directly.
