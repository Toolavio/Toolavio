## Che cos'è Toolavio?

Una raccolta di strumenti digitali utilizzabili dal browser per documenti, immagini, testo, dati, calcoli e altre attività quotidiane. Il catalogo riunisce più operazioni nella stessa interfaccia. Non significa che sostituisca ogni applicazione professionale specializzata.

## Questo è il codice sorgente dell'applicazione?

No. Il repository contiene presentazione pubblica, guide, roadmap e moduli per le segnalazioni. Non distribuisce sorgenti applicativi, motori di elaborazione, pacchetti di deploy o documentazione tecnica interna di Toolavio. Scaricare o clonare questo repository non installa Toolavio.

## 1.000 operazioni equivalgono a 1.000 applicazioni indipendenti?

No. Toolavio utilizza componenti di elaborazione condivisi per più operazioni configurate. La domanda utile è se uno specifico strumento accetta il tuo input e produce il risultato desiderato. Leggi formati e limiti prima di elaborare dati importanti.

## I miei file vengono caricati sul server?

Gli strumenti che supportano l'elaborazione locale trattano gli input nel browser, anziché inviarne i contenuti a Toolavio per quell'operazione. Il sito utilizza comunque connessioni di rete per pagine, risorse e servizi come l'accesso all'account. Elaborazione locale non significa assenza assoluta di attività di rete. Consulta il singolo strumento e la [pagina Privacy ufficiale](https://toolavio.com/it/privacy.html).

## Lo spazio locale conserva i miei file per sempre?

No. Progetti e risultati salvati esplicitamente in locale dipendono dallo spazio del browser corrente. Scadenza, navigazione privata, limiti di archiviazione o cancellazione dei dati del sito possono rimuoverli. Lo spazio locale non è sincronizzazione cloud né backup garantito. Conserva gli originali e scarica i risultati che vuoi mantenere.

## Serve un account?

Molti strumenti pubblici sono disponibili senza accesso. Le funzioni legate all'account e a Pro hanno requisiti propri. Verifica disponibilità e condizioni commerciali sul sito aggiornato: questo repository non duplica prezzi o regole di accesso.

## Posso usare Toolavio sul telefono o installarlo?

Toolavio è progettato per browser desktop e mobili. Installazione della web app e condivisione dei file dipendono da browser e sistema operativo. Segui le istruzioni della [pagina Offline](https://toolavio.com/it/offline/). Questo repository non distribuisce installer di app native e non dichiara supporto universale delle piattaforme.

## Funziona tutto offline?

No. Prepara i pacchetti supportati mentre sei online e verifica gli strumenti che intendi usare. Le risorse più grandi possono richiedere download specifici. I servizi dell'account e le operazioni che richiedono rete rimangono distinti dagli strumenti disponibili localmente.

## Cosa dimostra un controllo del risultato superato?

Soltanto le verifiche effettivamente eseguite, per esempio la sintassi JSON valida o un formato immagine leggibile. Non certifica universalmente significato, fedeltà visiva, accuratezza OCR, validità legale o idoneità per decisioni professionali. Controlla personalmente i risultati importanti.

## Posso combinare strumenti e condividere la procedura?

[Flow](https://toolavio.com/it/flow/) collega operazioni compatibili. Un flusso condiviso è una configurazione riutilizzabile: i destinatari forniscono i propri input. Condividere il collegamento pubblico di uno strumento è diverso dal condividere esplicitamente un file generato.

## Toolavio Core e Toolavio Action Engine sono installabili?

Sono iniziative di sviluppo. Core vuole rendere riutilizzabili autonomamente alcuni motori esistenti; TAE è l'integrazione prevista per siti esterni. Questo repository non offre un pacchetto Core già distribuito, un'edizione self-hosted, un SDK o un embed commerciale pronto da installare. Consulta la [roadmap](ROADMAP_IT.md).

## Dove segnalo un problema?

Usa i [moduli pubblici](https://github.com/Toolavio/Toolavio/issues/new/choose) per problemi riproducibili e suggerimenti privi di dati riservati. Per questioni dell'account contatta il [supporto](../SUPPORT.it.md). Le possibili vulnerabilità vanno segnalate in privato seguendo [SECURITY.it.md](../SECURITY.it.md), non in una issue pubblica.

## Dove trovo le note di rilascio aggiornate?

Sulla [pagina Aggiornamenti ufficiale](https://toolavio.com/it/updates.html). Il sito è il riferimento della cronologia del prodotto; i commit di questo repository descrivono modifiche alla documentazione pubblica, non release del software.
