# Frequently asked questions

[Overview](../README.md) · [Quick start](QUICK_START.md) · [Support](../SUPPORT.md)

## What is Toolavio?

A browser-based collection of digital tools for documents, images, text, data, calculations, and related everyday tasks. The catalog brings multiple operations into one interface. It is not a claim to replace every specialist professional application.

## Is this the application's source code?

No. This repository contains the public overview, user guidance, roadmap, and feedback forms. Toolavio's application source, processing engines, deployment packages, and internal technical documentation are not distributed here. Downloading or cloning this repository does not install Toolavio.

## Are 1,000 operations the same as 1,000 independent applications?

No. Toolavio uses shared processing components for multiple configured operations. The useful question is whether the particular tool accepts your input and produces the result you need. Read its formats and limits before processing important data.

## Are my files uploaded?

Tools that support local processing handle their inputs in your browser rather than uploading the contents to Toolavio for that operation. The website still needs network requests for pages, resources, and services such as account access. Do not interpret local file processing as a promise of zero network activity. Refer to each tool and the official [Privacy page](https://toolavio.com/en/privacy.html).

## Does the local workspace keep my files forever?

No. Explicitly saved local projects and results belong to the current browser's storage. Expiry, private browsing, storage limits, or clearing site data can remove them. Local storage is not cloud synchronization or a guaranteed backup. Keep original files and download results you need to retain.

## Do I need an account?

Many public tools are available without signing in. Account-based and Pro features have their own requirements. Check the current website for availability and commercial terms; this repository does not duplicate pricing or entitlement rules.

## Can I use Toolavio on a phone or install it?

Toolavio is designed for desktop and mobile browsers. Web-app installation and file sharing depend on the browser and operating system. Follow the instructions offered by the [Offline page](https://toolavio.com/en/offline/). This repository does not distribute native app installers or claim universal platform support.

## Does everything work offline?

No. Prepare supported toolkits while online and verify the tools you intend to use. Larger resources may need their own download. Account services and any operation that requires a network remain separate from locally available tools.

## What does a successful result check prove?

Only the checks actually performed, such as valid JSON syntax or a readable image format. It is not universal certification of meaning, visual fidelity, OCR accuracy, legal validity, or suitability for professional decisions. Review important results yourself.

## Can I combine tools and share the process?

[Flow](https://toolavio.com/en/flow/) connects compatible operations. A shared workflow is a reusable configuration; recipients supply their own inputs. Sharing a public tool link is different from explicitly sharing a generated file.

## Are Toolavio Core and Toolavio Action Engine available to install?

They are development initiatives. Core aims to make selected existing engines independently reusable; TAE is the planned website integration. This repository does not offer a released Core package, self-hosted edition, SDK, or ready-to-install commercial embed. See the [roadmap](ROADMAP.md).

## Where should I report a problem?

Use [public issue forms](https://github.com/Toolavio/Toolavio/issues/new/choose) for reproducible bugs and suggestions that contain no private data. For account matters, contact [support](../SUPPORT.md). Send suspected security issues privately following [SECURITY.md](../SECURITY.md), not in a public issue.

## Where are the current release notes?

On the official [Toolavio Updates page](https://toolavio.com/en/updates.html). The website is the product's release-history reference; GitHub commits here describe changes to the public documentation, not software releases.
