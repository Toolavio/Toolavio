# Segnalare un problema di sicurezza

[English — principale](SECURITY.md) · **Italiano** · [Deutsch](SECURITY.de.md)

**Non divulgare possibili vulnerabilità, credenziali o dati privati nelle issue, discussioni o pull request pubbliche di GitHub.**

## Contatto privato

Scrivi a [contact@toolavio.com](mailto:contact@toolavio.com?subject=Toolavio%20security%20report) con oggetto **Toolavio security report**.

Inizia con una descrizione minima del problema, l'URL pubblico o la funzione interessata, l'impatto osservato e passaggi sicuri per riprodurlo con dati sintetici. Quando rilevante, indica orario approssimativo, browser e sistema operativo.

Non allegare documenti privati degli utenti, credenziali, cookie di autenticazione, informazioni di pagamento o archivi software proprietari. L'email ordinaria non va trattata come un canale cifrato end-to-end: descrivi prima il problema e concorda, se necessario, un metodo appropriato per fornire materiale sensibile.

## Segnalazioni sicure

Utilizza soltanto i tuoi dati e account di prova. Non accedere ai dati di altri utenti, non interrompere il servizio, non eseguire test distruttivi e non continuare quando incontri informazioni alle quali non sei autorizzato ad accedere. Questo documento non autorizza test invasivi o accessi oltre i tuoi permessi.

## Ambito e aspettative

Questo repository pubblica documentazione, non il sorgente applicativo Toolavio. Le segnalazioni possono riguardare il servizio pubblico, comportamenti privacy errati o divulgazioni accidentali nella documentazione.

La pagina non istituisce un programma bug bounty, ricompense garantite, impegni sui tempi di risposta o certificazioni di sicurezza. La documentazione pubblica non deve esporre dettagli implementativi che rendano più facile sfruttare un problema irrisolto.
